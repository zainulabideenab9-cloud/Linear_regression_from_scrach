# Linear Regression from Scratch
[![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python)](https://www.python.org/) [![Jupyter](https://img.shields.io/badge/Explore-Jupyter-orange?logo=jupyter)](My_linear_regression_model.ipynb)
> A hands-on walkthrough of fitting and comparing linear regression models.
## ✨ Notebook walkthrough
- Build ordinary least squares from scratch with NumPy's normal equation.
- Split the built-in Diabetes dataset into 80% training and 20% test data.
- Compare the scratch model with scikit-learn's `LinearRegression`.
- Both implementations reach an R² score of about `0.4526` on the test set.
##  Data & files
- Explore 442 samples and 10 features; see the [notebook](My_linear_regression_model.ipynb) and [CSV data](combined_data.csv), [features](feature_data.csv), and [targets](target_data.csv).
## 🚀 Quick start
Install `numpy`, `scikit-learn`, and `notebook`, then run `jupyter notebook My_linear_regression_model.ipynb`.
